# Finetuning Pipelines

This directory contains pipelines for finetuning embedding models and LLMs for the RAG pipeline.

## Status
🚧 In Development

## Components

### Embedding Model Finetuning
- Domain-specific embedding model training
- Integration with synthetic data pipeline
- Evaluation and benchmarking

### LLM Finetuning for RAG
- Instruction tuning for RAG tasks
- Context-aware fine-tuning
- Integration with RAG pipeline
