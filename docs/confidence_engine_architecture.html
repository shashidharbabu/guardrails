⛔
HARD_BLOCK safety override — checked before the formula runs. If the MAD judge finds any material claim (a regulatory obligation, penalty, or threshold) scored 0.0, the answer is blocked immediately regardless of the overall confidence score. A fabricated regulatory claim can never reach the user via any retry path.
Data flow into CSE
From MAD Pipeline
• final_claims — list of Claim objects with is_material flag
• judge_verdicts — JudgeVerdict per claim (score: 0/0.5/1)
• evidence_pool — EvidenceChunk objects (RAG context text)
From caller
• query — original user question
• llm_answer — the full LLM response text
• rag_chunks — retrieved context (strings or Chunk objects)
CSE writes to DB
• final_cse_score — weighted formula result
• routing_decision — DELIVER / RETRY / etc.
• cse_f_llm, cse_h_llm
• cse_relevancy, cse_judge_eval
• cse_version — v2.0 or v0.1 (fallback)
